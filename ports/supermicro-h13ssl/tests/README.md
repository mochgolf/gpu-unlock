# Transaction fixtures

`native-unlock-golden.log` is a filtered proof log from the accepted native single-card transaction.
It retains only the proof lines that `verify_unlock_log.sh` requires.
The dual-card copy is a synthetic test fixture only.
For native dual-card acceptance, read the [benchmark report](../../../benchmarks/2026-10-26/README.md).
